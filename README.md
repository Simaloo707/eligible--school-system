# Eligible Pre & Primary School Management System

## About the Project

This project is being developed to create a simple digital management system for Eligible Pre & Primary School.

The system will be developed step by step so that it is easy to understand, test and improve.

## Phase 1: Online Student Admissions

The first phase will allow parents or guardians to submit student applications online.

The admission form will collect:

- Student's full name
- Date of birth
- Gender
- Parent or guardian name
- Parent phone number
- Email address
- Class applied for
- New admission or transfer student
- Previous school, where applicable

## Planned Future Phases

1. Student Register
2. School Fee Management
3. Attendance Management
4. Parent Notifications
5. Academic Records and Reports

## Project Goal

To develop a simple, affordable and easy-to-use school management system that can gradually grow with the school.
